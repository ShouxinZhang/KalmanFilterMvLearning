# Log4Human Template

```md
# <Task Title>

## Task

<one short paragraph: what the task was>

## Completed

- <concrete completed item 1>
- <concrete completed item 2>
- <concrete completed item 3>

## Key Result

- <one or two bullets with the most decision-relevant outcomes>

## Quick Verify

- Open: <file path to inspect first>
- Run: `<one command that quickly demonstrates the result>`
- Expect: <one short sentence about the expected outcome>

## Artifacts

- <file or directory path 1>: <why it matters>
- <file or directory path 2>: <why it matters>
- <file or directory path 3>: <why it matters>
```

Rules:

- 不写长篇过程复盘
- 不写 agent 间协调细节，除非它直接影响交付
- 不重复贴命令输出，除非其中有老板必须知道的结论
- `Quick Verify` 要足够短，最好 1 个文件 + 1 条命令 + 1 句预期
- 控制在一屏内，优先让人类快速扫读
