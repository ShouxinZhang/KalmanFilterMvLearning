\section{为什么需要粒子滤波}

Kalman filter 的核心优势，是把后验分布压缩成均值与协方差。只要系统近似线性、噪声近似高斯，这种压缩几乎不损失关键信息。

但如果后验分布本身不是单峰高斯，这种压缩就会失真。一个典型场景是：状态 \(x_t\) 是小车位置，观测却是
\[
y_t = x_t^2 + v_t,
\qquad
v_t \sim \Normal(0,\sigma_y^2).
\]
当你测到 \(y_t \approx 9\) 时，\(x_t \approx 3\) 和 \(x_t \approx -3\) 都有可能。后验天然呈现双峰结构，而不是单峰结构。此时若仍坚持用单个高斯去近似，就会把两个峰强行压缩为中间的一团分布。

粒子滤波的基本立场是：既然后验可能具有复杂结构，就不应强行将其压缩为单一的简单分布，而应直接用一批样本去近似整个后验。

\section{Bayes 滤波递推：粒子方法要近似的到底是什么}

考虑状态空间模型
\[
x_t \sim p(x_t \mid x_{t-1}), \qquad
y_t \sim p(y_t \mid x_t),
\]
其中状态空间记为 \(\mathcal X \subseteq \R^d\)，\(x_t \in \mathcal X\) 是隐状态，\(y_t\) 是观测。我们的目标是递推计算后验密度
\[
p(x_t \mid y_{1:t}),
\qquad
y_{1:t} := (y_1,\dots,y_t).
\]

\subsection{先看两个朴素例子}

如果一上来就看积分式，读者通常不知道自己到底在算什么。更好的方式，是先看一个离散例子，再看一个连续例子。

\paragraph{例 1：离散状态，其实就是“把所有旧状态的贡献加起来”}
设小车此刻只可能在两个路口：左路口 \(L\) 或右路口 \(R\)。上一时刻后验为
\[
\mathbb{P}(x_{t-1}=L \mid y_{1:t-1}) = 0.7,
\qquad
\mathbb{P}(x_{t-1}=R \mid y_{1:t-1}) = 0.3.
\]
状态转移满足
\[
\mathbb{P}(x_t=L \mid x_{t-1}=L)=0.8,
\qquad
\mathbb{P}(x_t=L \mid x_{t-1}=R)=0.2.
\]
那么由附录~\hyperref[app:total-prob]{全概率公式}的离散求和版，
\[
\mathbb{P}(x_t=L \mid y_{1:t-1})
= \sum_{x_{t-1}\in\{L,R\}}
\mathbb{P}(x_t=L \mid x_{t-1})\,
\mathbb{P}(x_{t-1} \mid y_{1:t-1}),
\]
于是
\[
\mathbb{P}(x_t=L \mid y_{1:t-1})
= 0.8\times 0.7 + 0.2\times 0.3
= 0.62.
\]
这说明预测步并不神秘，本质上只是把“所有可能的旧状态”都过一遍，然后把它们对当前状态的贡献加起来。

现在假设传感器在时刻 \(t\) 给出观测 \(y_t\)，且似然为
\[
\mathbb{P}(y_t \mid x_t=L)=0.9,
\qquad
\mathbb{P}(y_t \mid x_t=R)=0.2.
\]
那么由附录~\hyperref[app:bayes-formula]{Bayes 公式}，
\[
\mathbb{P}(x_t=L \mid y_{1:t})
\propto
\mathbb{P}(y_t \mid x_t=L)\,
\mathbb{P}(x_t=L \mid y_{1:t-1})
= 0.9\times 0.62 = 0.558,
\]
\[
\mathbb{P}(x_t=R \mid y_{1:t})
\propto
0.2\times 0.38 = 0.076.
\]
归一化后，
\[
\mathbb{P}(x_t=L \mid y_{1:t})
= \frac{0.558}{0.558+0.076}
\approx 0.88,
\qquad
\mathbb{P}(x_t=R \mid y_{1:t})
\approx 0.12.
\]
这就是更新步：先看预测分布，再用新观测重新分配可信度。

\paragraph{例 2：连续状态，其实就是“把所有旧位置的贡献累加起来”}
现在把状态改成连续位置。设上一时刻我们认为小车位置 \(x_{t-1}\) 在区间 \([4,6]\) 上均匀分布，即
\[
p(x_{t-1} \mid y_{1:t-1})
=
\begin{cases}
\frac12, & x_{t-1}\in[4,6],\\
0, & \text{其他}.
\end{cases}
\]
又设运动模型是
\[
x_t = x_{t-1} + w_t,
\qquad
w_t \sim \mathrm{Unif}[0,1],
\]
于是转移密度为
\[
p(x_t \mid x_{t-1})
=
\begin{cases}
1, & x_t\in[x_{t-1},\,x_{t-1}+1],\\
0, & \text{其他}.
\end{cases}
\]
这时若想算预测密度在 \(x_t=6\) 处的值，由附录~\hyperref[app:total-prob]{全概率公式}，
\[
p(x_t=6 \mid y_{1:t-1})
= \int_{\mathcal X} p(6 \mid x_{t-1})\, p(x_{t-1} \mid y_{1:t-1})\, dx_{t-1}.
\]
只有 \(x_{t-1}\in[5,6]\) 时，核 \(p(6 \mid x_{t-1})\) 才不为零，因此
\[
p(x_t=6 \mid y_{1:t-1})
= \int_{5}^{6} 1\cdot \frac12\, dx_{t-1}
= \frac12.
\]
同理，
\[
p(x_t=4.5 \mid y_{1:t-1})
= \int_{4}^{4.5} 1\cdot \frac12\, dx_{t-1}
= \frac14.
\]
这说明连续情形下，积分并不是额外的神秘操作；它只是把“所有可能的旧位置”对当前点 \(x_t\) 的贡献连续地累加起来。收到观测后，再按
\[
p(x_t \mid y_{1:t})
\propto
p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1})
\]
把靠近观测的位置抬高、把远离观测的位置压低，这就是连续版的更新。

\subsection{预测步}

由附录~\hyperref[app:total-prob]{全概率公式}，
\[
p(x_t \mid y_{1:t-1})
= \int_{\mathcal X} p(x_t \mid x_{t-1}) p(x_{t-1} \mid y_{1:t-1}) \, dx_{t-1}.
\]
这一步把上一时刻的后验经由状态转移核推到当前，称为预测分布。

\subsection{更新步}

由附录~\hyperref[app:bayes-formula]{Bayes 公式}，
\[
p(x_t \mid y_{1:t})
= \frac{p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1})}{p(y_t \mid y_{1:t-1})}.
\]
分母只是归一化常数，因此常写成
\[
p(x_t \mid y_{1:t})
\propto p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1}).
\]

合起来，Bayes 滤波就是一条两步递推：
\begin{align*}
\text{预测：}\quad
p(x_t \mid y_{1:t-1})
&= \int_{\mathcal X} p(x_t \mid x_{t-1}) p(x_{t-1} \mid y_{1:t-1}) \, dx_{t-1}, \\
\text{更新：}\quad
p(x_t \mid y_{1:t})
&\propto p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1}).
\end{align*}

难点不在公式，而在于这两个分布通常没有解析表达式。粒子滤波就是对这条递推的数值近似。若希望看“为什么这种数值近似会沿时间递推下去”的严格说明，可跳到附录~\hyperref[app:bayes-recursion]{为什么粒子滤波能够跟踪时间演化的后验分布}。

\section{用粒子近似分布}

如果你之前没系统学过 \(\pi_t^N\)、Dirac 质量、经验测度、先验/预测/后验分布这些术语，可以先跳到附录~\hyperref[app:notation]{术语与记号速查}；那一节专门解释这些词到底是什么意思，以及通常在哪些课程里第一次见到。

设一批粒子与权重为
\[
\{x_t^{(i)}, w_t^{(i)}\}_{i=1}^N,
\qquad
w_t^{(i)} \ge 0,\quad \sum_{i=1}^N w_t^{(i)} = 1.
\]
粒子滤波用经验测度
\[
\pi_t^N(dx)
= \sum_{i=1}^N w_t^{(i)} \delta_{x_t^{(i)}}(dx)
\]
近似目标后验 \(\pi_t(dx) = p(x_t \mid y_{1:t})\,dx\)。这里 \(\delta_{x_t^{(i)}}\) 是在粒子位置上的 Dirac 质量。若想先看两个直接可算的“近似后验”例子，可跳到附录~\hyperref[app:posterior-examples]{近似后验的两个朴素例子}。

于是对任意测试函数 \(\varphi\)，粒子系统自然诱导出一个后验期望的数值估计量：
\[
\widehat{I}_t^N(\varphi)
:=
\int_{\mathcal X} \varphi(x)\,\pi_t^N(dx)
=
\sum_{i=1}^N w_t^{(i)} \varphi(x_t^{(i)}).
\]
这个定义之所以重要，是因为滤波并不只关心“分布存在”，还关心如何从分布里提取可计算的量。最常见的两个量，是后验均值与二阶矩；前者给出位置型估计，后者则进一步进入方差、协方差和不确定性分析。关于这里两个等号为何成立，以及它与真实后验期望之间究竟是什么关系，可跳到附录~\hyperref[app:expectation-approx]{后验期望为何写成积分，以及粒子估计量为何逼近真实后验期望}。

因此，在 \(\varphi(x)=x\) 和 \(\varphi(x)=xx^\top\) 两个最常用的选择下，自然得到如下粒子估计量：
\[
\widehat{m}_t^N := \sum_{i=1}^N w_t^{(i)} x_t^{(i)},
\qquad
\widehat{M}_t^N := \sum_{i=1}^N w_t^{(i)} x_t^{(i)} {x_t^{(i)}}^\top.
\]
它们分别用来估计
\[
\E[x_t \mid y_{1:t}],
\qquad
\E[x_t x_t^\top \mid y_{1:t}].
\]

\section{从重要性采样推到权重递推}

\subsection{静态重要性采样}

设目标密度为 \(\pi(x)\)，难以直接采样；提议分布为 \(q(x)\)，容易采样，且 \(q(x) > 0\) 在 \(\pi(x)\) 的支撑上成立。则
\[
\E_\pi[\varphi(x)]
= \int_{\mathcal X} \varphi(x)\pi(x)\,dx
= \int_{\mathcal X} \varphi(x)\frac{\pi(x)}{q(x)} q(x)\,dx
= \E_q[\varphi(x)\omega(x)],
\]
其中未归一化重要性权重定义为
\[
\omega(x) := \frac{\pi(x)}{q(x)}.
\]

若 \(x^{(i)} \sim q\)，则自归一化估计为
\[
\E_\pi[\varphi(x)]
\approx \sum_{i=1}^N \bar{w}^{(i)} \varphi(x^{(i)}),
\qquad
\bar{w}^{(i)} = \frac{\omega(x^{(i)})}{\sum_{j=1}^N \omega(x^{(j)})}.
\]

\subsection{序贯重要性采样}

在滤波问题中，目标分布随时间变化。设整条状态轨迹为 \(x_{0:t}\)。目标是后验
\[
\pi_t(x_{0:t}) := p(x_{0:t} \mid y_{1:t}),
\]
而提议分布取作
\[
q_t(x_{0:t} \mid y_{1:t})
= q_{t-1}(x_{0:t-1} \mid y_{1:t-1}) q_t(x_t \mid x_{0:t-1}, y_{1:t}).
\]
对应的未归一化权重为
\[
\omega_t(x_{0:t})
= \frac{\pi_t(x_{0:t})}{q_t(x_{0:t} \mid y_{1:t})}.
\]

利用
\[
\pi_t(x_{0:t})
\propto p(y_t \mid x_t) p(x_t \mid x_{t-1}) \pi_{t-1}(x_{0:t-1}),
\]
可得递推形式
\[
\omega_t^{(i)}
\propto \omega_{t-1}^{(i)}
\frac{p(y_t \mid x_t^{(i)}) p(x_t^{(i)} \mid x_{t-1}^{(i)})}
{q_t(x_t^{(i)} \mid x_{0:t-1}^{(i)}, y_{1:t})}.
\]
这是序贯重要性采样的核心公式。
如果此时还分不清“状态转移分布、提议分布、后验分布”三者各自扮演什么角色，可先跳到附录~\hyperref[app:proposal-2d]{二维数值例子：状态转移分布、提议分布与后验分布的区别}；那一节专门用一个二维高斯例子把三者拆开比较。

\subsection{Bootstrap 粒子滤波}

若直接选提议分布
\[
q_t(x_t \mid x_{0:t-1}, y_{1:t}) = p(x_t \mid x_{t-1}),
\]
则上式中的状态转移项约掉，权重递推大幅简化为
\[
\omega_t^{(i)} \propto \omega_{t-1}^{(i)} p(y_t \mid x_t^{(i)}).
\]
这就是最经典的 Bootstrap particle filter。它的优点是实现简单；缺点是没有利用当前观测去设计更聪明的提议分布，故在观测很尖锐时容易权重退化。

\section{重采样：为什么必须做，以及怎么判断何时做}

\subsection{权重退化}

如果长时间只做重要性加权，不做重采样，通常会出现少数粒子拥有几乎全部权重，其余粒子权重接近零。此时虽名义上有 \(N\) 个粒子，实际有效样本远小于 \(N\)。

常用诊断量是有效样本数
\[
\ess
:= \frac{1}{\sum_{i=1}^N (w_t^{(i)})^2}.
\]
若所有权重都相等，则 \(\ess = N\)；若一个粒子独占全部权重，则 \(\ess = 1\)。

\subsection{重采样的数学作用}

重采样把带权粒子
\[
\{x_t^{(i)}, w_t^{(i)}\}_{i=1}^N
\]
转换为等权粒子
\[
\{\tilde{x}_t^{(i)}, 1/N\}_{i=1}^N
\]
并满足
\[
\E\!\left[\frac{1}{N}\sum_{i=1}^N \varphi(\tilde{x}_t^{(i)})
\Bigm| \{x_t^{(j)},w_t^{(j)}\}_{j=1}^N \right]
= \sum_{j=1}^N w_t^{(j)} \varphi(x_t^{(j)}).
\]
这说明：在给定当前带权粒子的条件下，重采样后的等权经验平均至少在条件期望层面保持不变。之所以此处要强调这一点，是因为重采样虽然会复制和删除粒子，但我们仍希望它不要系统性地扭曲当前已经形成的后验统计量。关于这一条件期望公式为何成立，以及它为什么并不意味着“信息完全不损失”，可跳到附录~\hyperref[app:resampling-unbiased]{重采样为何保持条件期望不变}。

\subsection{常见选择}

最简单的是 multinomial resampling。它直观，但方差偏大。实践中常用 systematic 或 stratified resampling，以降低采样方差。

\section{完整算法}

Bootstrap 粒子滤波可写成下述步骤：

\begin{enumerate}
  \item 初始采样：\(x_0^{(i)} \sim p(x_0)\)，令 \(w_0^{(i)} = 1/N\)。
  \item 预测：对每个粒子采样
  \[
  x_t^{(i)} \sim p(x_t \mid x_{t-1}^{(i)}).
  \]
  \item 加权：计算未归一化权重
  \[
  \omega_t^{(i)} = w_{t-1}^{(i)} p(y_t \mid x_t^{(i)}),
  \]
  再归一化成 \(w_t^{(i)}\)。
  \item 若 \(\ess < N_{\mathrm{thres}}\)，则重采样并把权重重置为 \(1/N\)。
\end{enumerate}

\section{算例一：双峰观测下的权重更新}

本节故意选一个一维、离散而短小的例子，用来手算权重。

\subsection{模型设定}

设当前时刻的预测粒子位置为
\[
x_t^{(1)}=-3,\quad x_t^{(2)}=-1,\quad x_t^{(3)}=1,\quad x_t^{(4)}=3,
\]
预测后它们等权，即 \(w_{t|t-1}^{(i)} = 1/4\)。

观测模型取为
\[
y_t = x_t^2 + v_t,\qquad v_t \sim \Normal(0,1).
\]
现在观测到 \(y_t = 9\)。

\subsection{逐个计算似然}

由高斯似然，
\[
p(y_t=9 \mid x_t^{(i)})
\propto \exp\!\left(-\frac{(9-(x_t^{(i)})^2)^2}{2}\right).
\]
四个粒子的平方分别为 \(9,1,1,9\)，故未归一化权重与
\[
\exp(0),\ \exp(-32),\ \exp(-32),\ \exp(0)
\]
成正比。记 \(a=\exp(-32)\approx 1.27\times 10^{-14}\)，则归一化后
\[
w_t^{(1)} = \frac{1}{2+2a}\approx \frac{1}{2},
\qquad
w_t^{(4)} = \frac{1}{2+2a}\approx \frac{1}{2},
\]
\[
w_t^{(2)} = w_t^{(3)} = \frac{a}{2+2a}\approx 6.35\times 10^{-15}.
\]

\subsection{这组数字说明了什么}

更新后，后验几乎完全集中在 \(-3\) 与 \(3\) 两个粒子上。这个结果非常重要：粒子滤波没有把答案压成 \(0\)，而是保留了两个对称峰。若此时用单个高斯去拟合后验，均值会落在 \(0\) 附近，但 \(0\) 恰好是观测最不支持的位置之一。

\subsection{有效样本数}

此时
\[
\ess
= \frac{1}{2(1/2)^2 + 2(6.35\times 10^{-15})^2}
\approx 2.
\]
虽然共有 \(4\) 个粒子，但有效样本数约为 \(2\)。继续迭代后若退化加重，就应触发重采样。

\section{算例二：一维非线性运动的两步递推}

上一节只手算了一次更新；这一节写出一个完整的预测-更新-重采样回合。

\subsection{模型}

取状态模型
\[
x_t = \frac{1}{2}x_{t-1} + w_t,\qquad w_t \sim \Normal(0,1),
\]
观测模型
\[
y_t = x_t^2 + v_t,\qquad v_t \sim \Normal(0,1).
\]
假设上一时刻重采样后得到四个等权粒子
\[
x_{t-1}^{(1)}=-4,\quad x_{t-1}^{(2)}=-2,\quad x_{t-1}^{(3)}=2,\quad x_{t-1}^{(4)}=4.
\]

\subsection{预测}

为了算例简单，假设一次实际采样结果恰为
\[
x_t^{(1)}=-3,\quad x_t^{(2)}=-1,\quad x_t^{(3)}=1,\quad x_t^{(4)}=3.
\]
这组值与状态方程是相容的，因为对应噪声样本分别为 \(-1,0,0,1\)。

\subsection{更新}

若观测仍是 \(y_t=9\)，则权重就是上一节算出的结果，近似为
\[
\left(\frac{1}{2},\,0,\,0,\,\frac{1}{2}\right).
\]

\subsection{重采样}

若做 multinomial resampling，则新粒子会以概率 \(1/2\) 从 \(-3\) 和 \(3\) 中抽取。一次可能的重采样结果为
\[
\tilde{x}_t^{(1)}=-3,\quad
\tilde{x}_t^{(2)}=-3,\quad
\tilde{x}_t^{(3)}=3,\quad
\tilde{x}_t^{(4)}=3.
\]
这说明重采样虽把权重重新拉平，但也明显减少了粒子多样性。这正是后续很多改进方法想要处理的问题。

\section{实现时真正要盯的量}

\subsection{粒子数 \(N\)}

\(N\) 太小时，后验分布会被表示得过于粗糙；\(N\) 太大时，计算开销上升。没有万能公式，通常只能依据维度、观测尖锐程度和实时性要求去调。

\subsection{提议分布}

Bootstrap 方案最简单，但不是最优。若观测很强，应该尝试设计更靠近后验的提议分布，否则权重容易一轮就塌。

\subsection{重采样阈值}

常见做法是在 \(\ess < N/2\) 或 \(\ess < 0.3N\) 时重采样。阈值过高会导致频繁重采样、样本贫化；阈值过低则权重退化严重。

\section{如果只记住几句话}

\begin{enumerate}
  \item 粒子滤波是在近似整条 Bayes 滤波递推，而不是只在做“随机采样”。
  \item 它用经验测度去逼近后验，因此天然可以表示多峰和强非线性。
  \item 重要性采样给出了权重公式，重采样则是在控制权重退化。
  \item 它的根本代价是：表达能力来自大量样本，算力与退化问题永远绕不开。
\end{enumerate}

\paragraph{后续关系}
在这份基础笔记之后，粒子滤波还可以与最优输运或神经网络结合。但那是两条不同扩展线，应分别讨论，而不应混在一篇里。

\section{术语与记号速查}\label{app:notation}

\subsection{这些东西通常在哪些课程里第一次见到}

如果按课程来源粗分，大致是这样：
\begin{enumerate}
  \item 概率论与数理统计：先验、后验、条件概率密度、Bayes 公式。
  \item 随机过程或状态估计：状态空间模型、预测分布、滤波递推。
  \item 测度论概率或更理论化的概率课：Dirac 质量、测度、经验测度这类写法。
  \item Monte Carlo / 统计计算：重要性采样、粒子系统、经验分布近似。
\end{enumerate}

所以如果你之前主要学的是“随机变量 + 密度函数 + 期望”那一套，而没正式学过测度论，那么 \(\pi_t^N(dx)\) 这种写法看着陌生是完全正常的。

\subsection{\(\pi_t\) 与 \(\pi_t^N\) 到底是什么}

这里的 \(\pi_t\) 只是“时刻 \(t\) 的目标后验分布”的另一种写法。连续情形下，它对应
\[
\pi_t(dx) = p(x_t \mid y_{1:t})\,dx.
\]

而 \(\pi_t^N\) 表示“用 \(N\) 个粒子构造出来的近似分布”：
\[
\pi_t^N(dx)
= \sum_{i=1}^N w_t^{(i)} \delta_{x_t^{(i)}}(dx).
\]

这里上标 \(N\) 不是幂次，而是在提醒你：这个对象依赖于粒子数 \(N\)。\(N\) 变大时，通常希望 \(\pi_t^N\) 越来越接近真正的后验 \(\pi_t\)。

\subsection{Dirac 质量是什么}

\(\delta_a\) 表示“把全部质量都压在点 \(a\) 上”的分布，也叫 Dirac 质量或点质量。最核心的特征是：对任意测试函数 \(\varphi\)，都有
\[
\int_{\mathcal X} \varphi(x)\,\delta_a(dx) = \varphi(a).
\]

如果你暂时不想碰测度论，可以把它粗略理解成：
\begin{quote}
\(\delta_a\) 就是在说“这个随机量不散开，它只取点 \(a\)”。
\end{quote}

所以
\[
\sum_{i=1}^N w_t^{(i)} \delta_{x_t^{(i)}}
\]
的意思就是：把权重 \(w_t^{(i)}\) 分配给点 \(x_t^{(i)}\)，从而得到一个“由很多带权点组成的分布”。

\subsection{经验测度是什么}

经验测度这个词听上去抽象，其实只是“把样本云写成分布对象”。

例如，若有三个等权样本
\[
2,\ 5,\ 9,
\]
那么对应的经验测度就是
\[
\frac13 \delta_2 + \frac13 \delta_5 + \frac13 \delta_9.
\]

它的意义是：以后你要算均值、方差或任意函数的期望时，不必每次都口头说“对三个样本取平均”，而可以统一写成“对经验测度积分”。比如
\[
\int_{\mathcal X} x\,
\left(
\frac13 \delta_2 + \frac13 \delta_5 + \frac13 \delta_9
\right)(dx)
= \frac{2+5+9}{3}.
\]

因此，粒子滤波里的经验测度不是新物理对象，只是把“粒子 + 权重”这堆东西打包成一个分布。

\subsection{先验、预测、后验分别是什么}

这三个概念彼此接近，但含义并不相同。

\begin{enumerate}
  \item 先验：在尚未利用当前观测之前，对状态所持有的分布性认识。
  \item 预测分布：把上一时刻后验通过状态转移推到当前时刻后得到的分布，即 \(p(x_t \mid y_{1:t-1})\)。
  \item 后验：融合了当前观测之后的分布，即 \(p(x_t \mid y_{1:t})\)。
\end{enumerate}

在滤波语境里，可以将三者的关系概括为：
\begin{quote}
先由上一时刻信息形成预测分布，再结合当前观测完成后验更新。
\end{quote}

\subsection{为什么正文里要用这些写法}

因为粒子滤波的本质不是只计算单个数值，而是在递推整条分布。只要关心的不仅是均值，而是完整的不确定性结构，那么 \(\pi_t\)、\(\pi_t^N\)、\(\delta_a\) 这一套写法会比单独书写密度函数更紧凑，也更适合同时处理离散与连续情形。

\subsection{近似后验的两个朴素例子}\label{app:posterior-examples}

\paragraph{例 1：离散状态时，近似后验就是带权计数}
设状态空间只有三个位置
\[
\mathcal X = \{A,B,C\}.
\]
假设真实后验为
\[
\pi_t(\{A\})=0.1,\qquad
\pi_t(\{B\})=0.3,\qquad
\pi_t(\{C\})=0.6.
\]

现在若粒子滤波给出 \(N=5\) 个等权粒子
\[
C,\ C,\ B,\ C,\ A,
\]
则经验测度就是
\[
\pi_t^5
= \frac15 \delta_A + \frac15 \delta_B + \frac35 \delta_C.
\]

这时它对三个状态给出的近似概率分别是
\[
\pi_t^5(\{A\})=\frac15,\qquad
\pi_t^5(\{B\})=\frac15,\qquad
\pi_t^5(\{C\})=\frac35.
\]

它与真实后验
\[
(0.1,\ 0.3,\ 0.6)
\]
并不完全相同，但已经抓住了最主要的结构：状态 \(C\) 概率最大，状态 \(A\) 最小。这里“近似后验”没有任何神秘之处，本质上就是“看有多少粒子落在各个状态上”。

\paragraph{例 2：连续状态时，近似后验就是带权点去逼近平滑分布}
现在设状态是连续位置，真实后验是一条平滑密度曲线，例如大致集中在 \(x=2\) 附近。粒子滤波给出三个带权粒子
\[
x_t^{(1)}=0,\qquad x_t^{(2)}=2,\qquad x_t^{(3)}=3,
\]
\[
w_t^{(1)}=0.2,\qquad w_t^{(2)}=0.5,\qquad w_t^{(3)}=0.3.
\]
那么近似后验写成
\[
\pi_t^3(dx)
= 0.2\,\delta_0(dx)+0.5\,\delta_2(dx)+0.3\,\delta_3(dx).
\]

这不表示真实后验真的只在 \(0,2,3\) 三个点取值，而是表示：
\begin{quote}
我们暂时只用这三个带权点来代表整条连续后验曲线。
\end{quote}

例如，它给出的后验均值近似为
\[
\int_{\mathcal X} x\,\pi_t^3(dx)
= 0.2\times 0 + 0.5\times 2 + 0.3\times 3
= 1.9.
\]

若要近似区间 \([1.5,3.5]\) 上的后验概率，则只需把落在区间内的粒子权重相加：
\[
\pi_t^3([1.5,3.5]) \approx 0.5+0.3=0.8.
\]

因此，连续情形下所谓“近似后验”，本质上就是：真实对象是一条连续密度曲线，而计算机里我们改用有限个带权点来替代它，并用这些权重去近似均值、区间概率和其他期望量。

\subsection{二维数值例子：状态转移分布、提议分布与后验分布的区别}\label{app:proposal-2d}

这三个对象最容易混淆，因此单独给一个二维例子。

\paragraph{模型设定}
为了只研究这三个分布的角色区别，我们先把上一时刻状态固定为
\[
x_{t-1} = \begin{bmatrix}0\\0\end{bmatrix}.
\]
设系统动力学给出的状态转移分布为
\[
p(x_t \mid x_{t-1})
= \Normal\!\left(
\begin{bmatrix}1\\1\end{bmatrix},
I_2
\right).
\]
这表示：如果只看系统运动规律，不看当前观测，那么下一时刻状态大致在 \((1,1)\) 附近，且不确定性较大。

当前观测模型取为
\[
y_t \mid x_t \sim \Normal(x_t,\,0.04\,I_2),
\qquad
y_t=
\begin{bmatrix}
2.8\\
2.6
\end{bmatrix}.
\]
这表示观测非常集中，强烈支持 \(x_t\) 靠近 \((2.8,2.6)\)。

\paragraph{第一步：状态转移分布在说什么}
状态转移分布
\[
p(x_t \mid x_{t-1})
\]
只回答一个问题：
\begin{quote}
如果暂时不看当前观测，系统本身倾向于怎样运动？
\end{quote}
在这个例子里，它把大量质量放在 \((1,1)\) 附近，因此这是系统先验上的“自然推进方向”。

\paragraph{第二步：后验分布在说什么}
真正想逼近的对象是后验分布
\[
p(x_t \mid y_t,x_{t-1})
\propto
p(y_t \mid x_t)\,p(x_t \mid x_{t-1}).
\]
由于这里转移与观测都是高斯，后验仍然是高斯，而且可以直接算出
\[
p(x_t \mid y_t,x_{t-1})
=
\Normal\!\left(
\begin{bmatrix}
2.7308\\
2.5385
\end{bmatrix},
\frac{1}{26}I_2
\right).
\]
所以后验的中心已经明显从 \((1,1)\) 被拉向了观测附近。这说明：后验不是单纯的“系统如何运动”，而是“系统运动规律与当前观测共同作用后的结果”。

\paragraph{第三步：提议分布在说什么}
提议分布
\[
q_t(x_t \mid x_{t-1},y_t)
\]
回答的不是“世界如何运动”，也不是“真实后验是什么”，而是：
\begin{quote}
算法实际准备从哪里抽样来生成候选粒子？
\end{quote}
因此它是算法设计对象，而不是物理真相本身。

\paragraph{第四步：Bootstrap 提议为何容易退化}
若直接取 Bootstrap 提议
\[
q_{\mathrm{boot}}(x_t \mid x_{t-1},y_t)
= p(x_t \mid x_{t-1}),
\]
也就是直接拿状态转移分布来采样。那么一组可能的二维粒子为
\[
(0.2,1.4),\quad (1.1,0.3),\quad (2.0,1.8),\quad (-0.1,0.7).
\]
由于此时 \(q_{\mathrm{boot}}=p(x_t\mid x_{t-1})\)，归一化前权重只与似然
\[
p(y_t \mid x_t^{(i)})
\]
成正比。数值上，归一化权重几乎变成
\[
(0,\ 0,\ 1,\ 0).
\]
对应的有效样本数约为
\[
\ess \approx 1.
\]
这说明：虽然系统转移允许算法在 \((1,1)\) 附近广泛采样，但当前观测非常尖锐，导致大部分粒子与观测不相容，于是权重几乎全部塌缩到一个粒子上。

\paragraph{第五步：一个更靠近后验的提议分布}
现在改用一个观测引导的提议分布：
\[
q_{\mathrm{guide}}(x_t \mid x_{t-1},y_t)
=
\Normal\!\left(
\begin{bmatrix}
2.7\\
2.5
\end{bmatrix},
0.09\,I_2
\right).
\]
这不是后验本身，但它刻意把采样中心放到了后验高概率区域附近。此时一组可能采样为
\[
(2.5,2.3),\quad (2.8,2.6),\quad (2.6,2.7),\quad (3.0,2.4).
\]
对应的重要性权重不再只由似然决定，而是
\[
\omega_t^{(i)}
\propto
\frac{p(y_t \mid x_t^{(i)})\,p(x_t^{(i)} \mid x_{t-1})}
{q_{\mathrm{guide}}(x_t^{(i)} \mid x_{t-1},y_t)}.
\]
数值上，归一化权重大致为
\[
(0.140,\ 0.377,\ 0.284,\ 0.199),
\]
对应有效样本数约为
\[
\ess \approx 3.55.
\]
与前面的 \(\ess \approx 1\) 相比，这说明更合适的提议分布会让粒子更早落在后验高概率区域，从而显著减轻退化。

\paragraph{第六步：三者到底怎么区分}
这个二维例子里，三者的角色已经完全不同：
\begin{enumerate}
  \item 状态转移分布：系统本身怎么运动。在本例中，它把质量放在 \((1,1)\) 附近。
  \item 提议分布：算法实际从哪里抽粒子。它可以等于状态转移分布，也可以更靠近观测。
  \item 后验分布：结合观测后真正想逼近的目标。在本例中，它集中在 \((2.7308,2.5385)\) 附近。
\end{enumerate}

仓库里附了

运行方式是：

\subsection{为什么粒子滤波能够跟踪时间演化的后验分布}\label{app:bayes-recursion}

正文里说过一句话：粒子滤波之所以能够跟踪“分布随时间的演化”，不是因为粒子本身神奇，而是因为它在数值上逼近了 Bayes 滤波递推。下面把这句话写成一个严格的命题。

\paragraph{第一步：把滤波递推写成两个算子}
设状态空间为 \(\mathcal X\)，状态转移核为
\[
K_t(\xi, A) := \mathbb P(x_t \in A \mid x_{t-1}=\xi),
\]
观测似然记为
\[
g_t(x) := p(y_t \mid x).
\]

给定任意概率测度 \(\mu\)，定义预测算子
\[
\Phi_t(\mu)(A)
:=
\int_{\mathcal X} K_t(\xi,A)\,\mu(d\xi),
\]
以及更新算子
\[
\Psi_t(\mu)(dx)
:=
\frac{g_t(x)\,\mu(dx)}
{\int_{\mathcal X} g_t(z)\,\mu(dz)}.
\]

于是 Bayes 滤波递推可以压缩写成
\[
\bar\pi_t = \Phi_t(\pi_{t-1}),
\qquad
\pi_t = \Psi_t(\bar\pi_t),
\]
其中 \(\bar\pi_t\) 是预测分布，\(\pi_t\) 是后验分布。

\paragraph{第二步：先说明要证明什么}
粒子滤波在时刻 \(t-1\) 给出一个近似测度 \(\pi_{t-1}^N\)。我们真正想证明的是：
\begin{quote}
如果 \(\pi_{t-1}^N\) 已经逼近 \(\pi_{t-1}\)，那么经过预测算子和更新算子之后，新的近似 \(\pi_t^N\) 仍然逼近 \(\pi_t\)。
\end{quote}
这正是“它能够跟踪时间演化分布”的数学内容。

\paragraph{第三步：一般情形下的命题}
设 \(\varphi\) 是任意有界连续测试函数，并假设：
\begin{enumerate}
  \item \(\pi_{t-1}^N \Rightarrow \pi_{t-1}\) 弱收敛；
  \item 转移核 \(K_t\) 具有 Feller 性质，即对任意有界连续 \(\varphi\)，函数
  \[
  (K_t\varphi)(\xi)
  :=
  \int_{\mathcal X}\varphi(x)\,K_t(\xi,dx)
  \]
  仍是有界连续函数；
  \item 似然 \(g_t\) 有界、连续，且
  \[
  \int_{\mathcal X} g_t(x)\,\Phi_t(\pi_{t-1})(dx) > 0.
  \]
\end{enumerate}
定义
\[
\bar\pi_t^N := \Phi_t(\pi_{t-1}^N),
\qquad
\pi_t^N := \Psi_t(\bar\pi_t^N).
\]
则有
\[
\bar\pi_t^N \Rightarrow \bar\pi_t,
\qquad
\pi_t^N \Rightarrow \pi_t.
\]

\paragraph{第四步：预测步的严格证明}
对任意有界连续 \(\varphi\)，有
\[
\int_{\mathcal X}\varphi(x)\,\bar\pi_t^N(dx)
=
\int_{\mathcal X}\varphi(x)\,\Phi_t(\pi_{t-1}^N)(dx).
\]
按 \(\Phi_t\) 的定义改写：
\[
\int_{\mathcal X}\varphi(x)\,\bar\pi_t^N(dx)
=
\int_{\mathcal X}
\left(
\int_{\mathcal X}\varphi(x)\,K_t(\xi,dx)
\right)
\pi_{t-1}^N(d\xi).
\]
记
\[
(K_t\varphi)(\xi)
:=
\int_{\mathcal X}\varphi(x)\,K_t(\xi,dx),
\]
则上式化为
\[
\int_{\mathcal X}\varphi(x)\,\bar\pi_t^N(dx)
=
\int_{\mathcal X}(K_t\varphi)(\xi)\,\pi_{t-1}^N(d\xi).
\]
由于 \(K_t\) 具有 Feller 性质，\(K_t\varphi\) 仍是有界连续函数；再由
\(\pi_{t-1}^N \Rightarrow \pi_{t-1}\)，得到
\[
\int_{\mathcal X}(K_t\varphi)(\xi)\,\pi_{t-1}^N(d\xi)
\to
\int_{\mathcal X}(K_t\varphi)(\xi)\,\pi_{t-1}(d\xi).
\]
把定义代回，即
\[
\int_{\mathcal X}\varphi(x)\,\bar\pi_t^N(dx)
\to
\int_{\mathcal X}\varphi(x)\,\bar\pi_t(dx).
\]
因此
\[
\bar\pi_t^N \Rightarrow \bar\pi_t.
\]

\paragraph{第五步：更新步的严格证明}
更新后，对任意有界连续 \(\varphi\)，有
\[
\int_{\mathcal X}\varphi(x)\,\pi_t^N(dx)
=
\frac{\int_{\mathcal X}\varphi(x)\,g_t(x)\,\bar\pi_t^N(dx)}
{\int_{\mathcal X}g_t(x)\,\bar\pi_t^N(dx)}.
\]
因为 \(\varphi\) 与 \(g_t\) 都有界连续，所以 \(\varphi g_t\) 与 \(g_t\) 仍是有界连续函数。由刚证明的
\(\bar\pi_t^N \Rightarrow \bar\pi_t\)，便有
\[
\int_{\mathcal X}\varphi(x)\,g_t(x)\,\bar\pi_t^N(dx)
\to
\int_{\mathcal X}\varphi(x)\,g_t(x)\,\bar\pi_t(dx),
\]
\[
\int_{\mathcal X}g_t(x)\,\bar\pi_t^N(dx)
\to
\int_{\mathcal X}g_t(x)\,\bar\pi_t(dx).
\]
又由于极限分母严格为正，因此商收敛，于是
\[
\int_{\mathcal X}\varphi(x)\,\pi_t^N(dx)
\to
\int_{\mathcal X}\varphi(x)\,\pi_t(dx).
\]
这就证明了
\[
\pi_t^N \Rightarrow \pi_t.
\]

\paragraph{第六步：这一定理真正说明了什么}
它说明：粒子滤波之所以能跟踪时间演化的后验分布，并不是因为“粒子会自动长成正确形状”，而是因为 Bayes 递推本身可分解为预测算子与更新算子，而这两个算子在适当条件下都会保留近似的一致性。

换句话说：
\begin{quote}
上一时刻若近似正确，下一时刻经过 Bayes 预测与更新后，近似仍然可以继续传递下去。
\end{quote}

\paragraph{第七步：这和实际粒子滤波之间还差哪一步}
上面的命题把重点放在“Bayes 算子如何传递近似”上。真正的粒子滤波还包含采样和重采样的随机机制，因此完整证明通常还要再加上：
\begin{enumerate}
  \item 采样经验测度对目标测度的一致性；
  \item 重采样步骤的条件无偏性与方差控制；
  \item 逐时刻归纳，得到整个粒子系统的一致性。
\end{enumerate}
但从结构上讲，决定它为何能跟踪时间演化分布的核心，正是上面这条“Bayes 算子保一致性”的命题。

\paragraph{第八步：一维状态的简化证明}
现在把状态空间专门取成 \(\mathcal X=\R\)，并设上一时刻的粒子近似为
\[
\pi_{t-1}^N(d\xi)=\sum_{i=1}^N w_{t-1}^{(i)}\delta_{x_{t-1}^{(i)}}(d\xi).
\]
设转移密度写成
\[
k_t(x\mid \xi),
\]
于是预测近似测度为
\[
\bar\pi_t^N(dx)
=
\sum_{i=1}^N w_{t-1}^{(i)}k_t(x\mid x_{t-1}^{(i)})\,dx.
\]

取任意有界连续测试函数 \(\varphi:\R\to\R\)。则
\[
\int_{\R}\varphi(x)\,\bar\pi_t^N(dx)
=
\sum_{i=1}^N w_{t-1}^{(i)}
\int_{\R}\varphi(x)\,k_t(x\mid x_{t-1}^{(i)})\,dx.
\]
定义
\[
T_t\varphi(\xi)
:=
\int_{\R}\varphi(x)\,k_t(x\mid \xi)\,dx,
\]
则上式可写成
\[
\int_{\R}\varphi(x)\,\bar\pi_t^N(dx)
=
\sum_{i=1}^N w_{t-1}^{(i)}\,T_t\varphi(x_{t-1}^{(i)})
=
\int_{\R}T_t\varphi(\xi)\,\pi_{t-1}^N(d\xi).
\]
若 \(\pi_{t-1}^N \Rightarrow \pi_{t-1}\)，且 \(T_t\varphi\) 有界连续，则
\[
\int_{\R}T_t\varphi(\xi)\,\pi_{t-1}^N(d\xi)
\to
\int_{\R}T_t\varphi(\xi)\,\pi_{t-1}(d\xi)
=
\int_{\R}\varphi(x)\,\bar\pi_t(dx).
\]
因此预测步保持一致性。

再设似然函数为
\[
g_t(x)=p(y_t\mid x).
\]
更新后的粒子测度定义为
\[
\pi_t^N(dx)
=
\frac{g_t(x)\,\bar\pi_t^N(dx)}
{\int_{\R}g_t(z)\,\bar\pi_t^N(dz)}.
\]
于是
\[
\int_{\R}\varphi(x)\,\pi_t^N(dx)
=
\frac{\int_{\R}\varphi(x)g_t(x)\,\bar\pi_t^N(dx)}
{\int_{\R}g_t(x)\,\bar\pi_t^N(dx)}.
\]
若 \(\bar\pi_t^N \Rightarrow \bar\pi_t\)，且 \(\varphi g_t\)、\(g_t\) 都有界连续，分母极限严格正，则分子分母分别收敛，从而
\[
\int_{\R}\varphi(x)\,\pi_t^N(dx)
\to
\int_{\R}\varphi(x)\,\pi_t(dx).
\]
因此一维情形下，粒子近似之所以能够随时间跟踪后验分布，本质上仍然是：预测算子与更新算子把上一时刻的近似继续传到了下一时刻。

\subsection{后验期望为何写成积分，以及粒子估计量为何逼近真实后验期望}\label{app:expectation-approx}

正文里出现过下面这一步：
\[
\widehat{I}_t^N(\varphi)
:=
\int_{\mathcal X} \varphi(x)\,\pi_t^N(dx)
=
\sum_{i=1}^N w_t^{(i)} \varphi(x_t^{(i)}).
\]
而它所对应的真实目标量是
\[
I_t(\varphi)
:=
\E[\varphi(x_t)\mid y_{1:t}]
=
\int_{\mathcal X}\varphi(x)\,\pi_t(dx).
\]
对初学者而言，最容易困惑的是：这些等号各自依据什么，以及为什么 \(\widehat{I}_t^N(\varphi)\) 可以拿来估计 \(I_t(\varphi)\)。下面分开说明。

\paragraph{第一步：为什么
\(\E[\varphi(x_t) \mid y_{1:t}]
= \int_{\mathcal X} \varphi(x)\,\pi_t(dx)\)
是等号}
这一步没有做任何近似，它只是把“条件期望”换写成“对后验分布积分”。

因为我们已经把时刻 \(t\) 的后验分布记成
\[
\pi_t(dx)=p(x_t\mid y_{1:t})\,dx.
\]
所以按照期望对分布积分的定义，
\[
\E[\varphi(x_t)\mid y_{1:t}]
= \int_{\mathcal X} \varphi(x)\,p(x_t\mid y_{1:t})\,dx
= \int_{\mathcal X} \varphi(x)\,\pi_t(dx).
\]
因此这里的等号只是记号改写：左边是“条件期望”的写法，右边是“相对于后验分布积分”的写法，二者表示的是同一个量。

\paragraph{第二步：粒子滤波并不直接得到 \(\pi_t\)，而是先构造经验测度}
粒子滤波输出的是粒子与权重，因此首先得到的是经验测度
\[
\pi_t^N(dx)=\sum_{i=1}^N w_t^{(i)}\delta_{x_t^{(i)}}(dx).
\]
于是把 \(\varphi\) 对 \(\pi_t^N\) 积分，就定义出粒子估计量
\[
\widehat{I}_t^N(\varphi)
:=
\int_{\mathcal X}\varphi(x)\,\pi_t^N(dx)
=
\int_{\mathcal X}\varphi(x)\,
\left(\sum_{i=1}^N w_t^{(i)}\delta_{x_t^{(i)}}(dx)\right).
\]

\paragraph{第三步：为什么
\(\widehat{I}_t^N(\varphi)
= \sum_{i=1}^N w_t^{(i)}\varphi(x_t^{(i)})\)
仍然是等号}
这一步同样不是近似，而是 Dirac 质量的定义性性质。

先把常数权重提出，再逐项积分：
\[
\widehat{I}_t^N(\varphi)
= \sum_{i=1}^N w_t^{(i)}
\int_{\mathcal X}\varphi(x)\,\delta_{x_t^{(i)}}(dx).
\]

而 Dirac 质量满足
\[
\int_{\mathcal X}\varphi(x)\,\delta_{x_t^{(i)}}(dx)
= \varphi(x_t^{(i)}).
\]
代回即得
\[
\widehat{I}_t^N(\varphi)
= \sum_{i=1}^N w_t^{(i)}\varphi(x_t^{(i)}).
\]
所以这一小步仍然是严格等式。

\paragraph{第四步：逼近关系究竟发生在哪里}
真正需要说明的，不是“积分如何变成求和”，而是经验测度为何可以逼近真实后验。更准确地说，我们需要的是
\[
\widehat{I}_t^N(\varphi) - I_t(\varphi) \to 0
\qquad (N\to\infty)
\]
这样的收敛结论。若用概率收敛来表述，可以写成
\[
\widehat{I}_t^N(\varphi) - I_t(\varphi)
\xrightarrow[]{\mathbb P} 0,
\qquad N\to\infty,
\]
其中需要对模型、权重和测试函数 \(\varphi\) 施加适当假设。这才是严格的数学表述。

如果进一步研究中心极限定理，常可得到更细的误差尺度，例如
\[
\widehat{I}_t^N(\varphi) - I_t(\varphi)
= O_{\mathbb P}(N^{-1/2}),
\]
但这已经依赖更强的技术条件，不能在正文里不加说明地直接写成一个普通的“约等于”。

\paragraph{第五步：把逻辑压缩成一句话}
因此，正确的理解顺序不是
\begin{quote}
积分大概等于求和，
\end{quote}
而是
\begin{quote}
先定义真实目标量 \(I_t(\varphi)\)，再定义粒子估计量 \(\widehat{I}_t^N(\varphi)\)；随后在一致性或渐近理论下证明 \(\widehat{I}_t^N(\varphi)\) 逼近 \(I_t(\varphi)\)。
\end{quote}

\paragraph{一个最小数值例子}
设
\[
\pi_t^3(dx)=0.2\,\delta_0(dx)+0.5\,\delta_2(dx)+0.3\,\delta_3(dx),
\qquad
\varphi(x)=x^2.
\]
那么
\[
= \widehat{I}_t^3(\varphi)
= \int_{\mathcal X} x^2\,\pi_t^3(dx)
= 0.2\cdot 0^2 + 0.5\cdot 2^2 + 0.3\cdot 3^2
= 4.7.
\]
这里最后一步不是近似，而是严格计算。若进一步用它估计
\[
I_t(x^2)
= \E[x_t^2\mid y_{1:t}]
= \int_{\mathcal X} x^2\,\pi_t(dx),
\]
则严格写法应是考察误差
\[
\widehat{I}_t^3(x^2)-I_t(x^2),
\]
并在 \(N\) 增大时讨论它是否趋于 \(0\)，而不是直接写一个没有说明误差含义的近似号。

\subsection{重采样为何保持条件期望不变}\label{app:resampling-unbiased}

正文里写过下面这条公式：
\[
\E\!\left[\frac{1}{N}\sum_{i=1}^N \varphi(\tilde{x}_t^{(i)})
\Bigm| \{x_t^{(j)},w_t^{(j)}\}_{j=1}^N \right]
= \sum_{j=1}^N w_t^{(j)} \varphi(x_t^{(j)}).
\]
这句话看起来很强，因此必须先问：为什么这里要研究它？

\paragraph{第一步：为什么要引入这条公式}
因为重采样会把带权粒子
\[
\{x_t^{(j)},w_t^{(j)}\}_{j=1}^N
\]
改成等权粒子
\[
\{\tilde x_t^{(i)},1/N\}_{i=1}^N.
\]
这一过程显然会改变样本的具体排列，甚至会删除一些粒子、复制另一些粒子。因此自然要追问：
\begin{quote}
重采样之后，我们用等权粒子算出来的平均量，会不会系统性偏离重采样之前的带权平均？
\end{quote}
上面的条件期望公式正是在回答这个问题。它说明：至少对经验平均而言，multinomial resampling 在条件期望意义下是无偏的。

\paragraph{第二步：先把重采样写成随机索引}
以 multinomial resampling 为例。给定当前粒子与权重后，重采样等价于独立抽取索引
\[
A_1,\dots,A_N \in \{1,\dots,N\},
\]
并满足
\[
\mathbb P(A_i=j \mid \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N)=w_t^{(j)}.
\]
然后定义
\[
\tilde x_t^{(i)} := x_t^{(A_i)}.
\]
也就是说，每个新粒子都是“按权重随机选一个旧粒子作为祖先”得到的。

\paragraph{第三步：先求单个重采样粒子的条件期望}
固定某个 \(i\)。在给定当前粒子与权重的条件下，
\[
\E[\varphi(\tilde x_t^{(i)}) \mid \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N]
= \sum_{j=1}^N \mathbb P(A_i=j \mid \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N)\,\varphi(x_t^{(j)}).
\]
把条件概率替换成权重，即得
\[
\E[\varphi(\tilde x_t^{(i)}) \mid \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N]
= \sum_{j=1}^N w_t^{(j)} \varphi(x_t^{(j)}).
\]
这说明：单个重采样粒子的函数值，其条件期望就已经等于原先的带权平均。

\paragraph{第四步：再推广到 \(N\) 个等权粒子的平均}
现在看重采样后的等权经验平均：
\[
\frac1N\sum_{i=1}^N \varphi(\tilde x_t^{(i)}).
\]
对它取条件期望，并利用期望的线性性，有
\[
\E\!\left[\frac1N\sum_{i=1}^N \varphi(\tilde x_t^{(i)})
\Bigm| \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N\right]
=
\frac1N\sum_{i=1}^N
\E[\varphi(\tilde x_t^{(i)}) \mid \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N].
\]
代入上一步结果：
\[
\E\!\left[\frac1N\sum_{i=1}^N \varphi(\tilde x_t^{(i)})
\Bigm| \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N\right]
=
\frac1N\sum_{i=1}^N
\sum_{j=1}^N w_t^{(j)} \varphi(x_t^{(j)}).
\]
由于右边与 \(i\) 无关，故
\[
\E\!\left[\frac1N\sum_{i=1}^N \varphi(\tilde x_t^{(i)})
\Bigm| \{x_t^{(k)},w_t^{(k)}\}_{k=1}^N\right]
=
\sum_{j=1}^N w_t^{(j)} \varphi(x_t^{(j)}).
\]
这就得到正文中的条件期望公式。

\paragraph{第五步：这条公式到底说明了什么，又没有说明什么}
它说明的是：
\begin{quote}
重采样后的等权经验平均，在条件期望意义下，与重采样前的带权经验平均一致。
\end{quote}
但它没有说明：
\begin{enumerate}
  \item 单次重采样的结果一定等于原带权平均；
  \item 重采样不会增加方差；
  \item 重采样不会降低样本多样性。
\end{enumerate}
恰恰相反，重采样通常会引入额外随机性，并可能导致粒子复制，从而降低多样性。它保住的是“条件期望无偏”，而不是“每次实现都无损”。

\paragraph{一个最小离散例子}
设当前只有两个粒子
\[
x_t^{(1)}=0,\qquad x_t^{(2)}=10,
\]
权重为
\[
w_t^{(1)}=0.8,\qquad w_t^{(2)}=0.2.
\]
取测试函数 \(\varphi(x)=x\)。则重采样前的带权平均为
\[
0.8\cdot 0 + 0.2\cdot 10 = 2.
\]

若 \(N=2\) 并做 multinomial resampling，则每个新粒子都以概率 \(0.8\) 取 \(0\)，以概率 \(0.2\) 取 \(10\)。于是单个新粒子的条件期望为
\[
\E[\tilde x_t^{(i)} \mid \{x_t^{(j)},w_t^{(j)}\}_{j=1}^2]
= 0.8\cdot 0 + 0.2\cdot 10 = 2.
\]
因此
\[
\E\!\left[\frac{\tilde x_t^{(1)}+\tilde x_t^{(2)}}{2}
\Bigm| \{x_t^{(j)},w_t^{(j)}\}_{j=1}^2\right]
= 2.
\]
但一次具体实现可能是
\[
(0,0),\qquad (0,10),\qquad (10,0),\qquad (10,10),
\]
它们对应的等权平均分别是
\[
0,\qquad 5,\qquad 5,\qquad 10.
\]
可见单次结果波动很大；真正保持不变的是条件期望，而不是每次实现本身。

\section{基础概率公式附录}

\subsection{全概率公式}\label{app:total-prob}

设 \(X\) 与 \(Y\) 具有联合密度 \(p(x,y)\)，其中 \(x \in \mathcal X\)。则边缘密度可由条件密度积分得到：
\[
p(y) = \int_{\mathcal X} p(y \mid x)\, p(x)\, dx.
\]

在条件化情形下，如果再给定一个额外信息集 \(\mathcal G\)，同样有
\[
p(y \mid \mathcal G)
= \int_{\mathcal X} p(y \mid x,\mathcal G)\, p(x \mid \mathcal G)\, dx.
\]

粒子滤波预测步正是在 \(\mathcal G = y_{1:t-1}\) 的条件下，对上式的直接应用。

\subsection{Bayes 公式}\label{app:bayes-formula}

在同样设定下，若 \(p(y) > 0\)，则后验密度满足
\[
p(x \mid y) = \frac{p(y \mid x)\, p(x)}{p(y)}.
\]
其中分母也可以借助全概率公式写成
\[
p(y) = \int_{\mathcal X} p(y \mid x)\, p(x)\, dx.
\]

若给定额外信息集 \(\mathcal G\)，则条件版 Bayes 公式为
\[
p(x \mid y,\mathcal G)
= \frac{p(y \mid x,\mathcal G)\, p(x \mid \mathcal G)}
{p(y \mid \mathcal G)}.
\]

粒子滤波更新步对应的是 \(\mathcal G = y_{1:t-1}\) 的特殊情形。
