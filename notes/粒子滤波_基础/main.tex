\section{为什么需要粒子滤波}

Kalman filter 的核心优势，是把后验分布压缩成均值与协方差。只要系统近似线性、噪声近似高斯，这种压缩几乎不损失关键信息。

但如果后验分布本身不是单峰高斯，这种压缩就会失真。一个典型场景是：状态 \(x_t\) 是小车位置，观测却是
\[
y_t = x_t^2 + v_t,
\qquad
v_t \sim \Normal(0,\sigma_y^2).
\]
当你测到 \(y_t \approx 9\) 时，\(x_t \approx 3\) 和 \(x_t \approx -3\) 都有可能。后验天然呈现双峰结构，而不是单峰结构。此时若仍坚持用单个高斯去近似，就会把两个峰强行压缩为中间的一团分布。

粒子滤波的基本立场是：既然后验可能具有复杂结构，就不应强行将其压缩为单一的简单分布，而应直接用一批样本去近似整个后验。

\section{Bayes 滤波递推：粒子方法要近似的到底是什么}

考虑状态空间模型
\[
x_t \sim p(x_t \mid x_{t-1}), \qquad
y_t \sim p(y_t \mid x_t),
\]
其中状态空间记为 \(\mathcal X \subseteq \R^d\)，\(x_t \in \mathcal X\) 是隐状态，\(y_t\) 是观测。我们的目标是递推计算后验密度
\[
p(x_t \mid y_{1:t}),
\qquad
y_{1:t} := (y_1,\dots,y_t).
\]

\subsection{先看两个朴素例子}

如果一上来就看积分式，读者通常不知道自己到底在算什么。更好的方式，是先看一个离散例子，再看一个连续例子。

\paragraph{例 1：离散状态，其实就是“把所有旧状态的贡献加起来”}
设小车此刻只可能在两个路口：左路口 \(L\) 或右路口 \(R\)。上一时刻后验为
\[
\mathbb{P}(x_{t-1}=L \mid y_{1:t-1}) = 0.7,
\qquad
\mathbb{P}(x_{t-1}=R \mid y_{1:t-1}) = 0.3.
\]
状态转移满足
\[
\mathbb{P}(x_t=L \mid x_{t-1}=L)=0.8,
\qquad
\mathbb{P}(x_t=L \mid x_{t-1}=R)=0.2.
\]
那么由附录~\hyperref[app:total-prob]{全概率公式}的离散求和版，
\[
\mathbb{P}(x_t=L \mid y_{1:t-1})
= \sum_{x_{t-1}\in\{L,R\}}
\mathbb{P}(x_t=L \mid x_{t-1})\,
\mathbb{P}(x_{t-1} \mid y_{1:t-1}),
\]
于是
\[
\mathbb{P}(x_t=L \mid y_{1:t-1})
= 0.8\times 0.7 + 0.2\times 0.3
= 0.62.
\]
这说明预测步并不神秘，本质上只是把“所有可能的旧状态”都过一遍，然后把它们对当前状态的贡献加起来。

现在假设传感器在时刻 \(t\) 给出观测 \(y_t\)，且似然为
\[
\mathbb{P}(y_t \mid x_t=L)=0.9,
\qquad
\mathbb{P}(y_t \mid x_t=R)=0.2.
\]
那么由附录~\hyperref[app:bayes-formula]{Bayes 公式}，
\[
\mathbb{P}(x_t=L \mid y_{1:t})
\propto
\mathbb{P}(y_t \mid x_t=L)\,
\mathbb{P}(x_t=L \mid y_{1:t-1})
= 0.9\times 0.62 = 0.558,
\]
\[
\mathbb{P}(x_t=R \mid y_{1:t})
\propto
0.2\times 0.38 = 0.076.
\]
归一化后，
\[
\mathbb{P}(x_t=L \mid y_{1:t})
= \frac{0.558}{0.558+0.076}
\approx 0.88,
\qquad
\mathbb{P}(x_t=R \mid y_{1:t})
\approx 0.12.
\]
这就是更新步：先看预测分布，再用新观测重新分配可信度。

\paragraph{例 2：连续状态，其实就是“把所有旧位置的贡献累加起来”}
现在把状态改成连续位置。设上一时刻我们认为小车位置 \(x_{t-1}\) 在区间 \([4,6]\) 上均匀分布，即
\[
p(x_{t-1} \mid y_{1:t-1})
=
\begin{cases}
\frac12, & x_{t-1}\in[4,6],\\
0, & \text{其他}.
\end{cases}
\]
又设运动模型是
\[
x_t = x_{t-1} + w_t,
\qquad
w_t \sim \mathrm{Unif}[0,1],
\]
于是转移密度为
\[
p(x_t \mid x_{t-1})
=
\begin{cases}
1, & x_t\in[x_{t-1},\,x_{t-1}+1],\\
0, & \text{其他}.
\end{cases}
\]
这时若想算预测密度在 \(x_t=6\) 处的值，由附录~\hyperref[app:total-prob]{全概率公式}，
\[
p(x_t=6 \mid y_{1:t-1})
= \int_{\mathcal X} p(6 \mid x_{t-1})\, p(x_{t-1} \mid y_{1:t-1})\, dx_{t-1}.
\]
只有 \(x_{t-1}\in[5,6]\) 时，核 \(p(6 \mid x_{t-1})\) 才不为零，因此
\[
p(x_t=6 \mid y_{1:t-1})
= \int_{5}^{6} 1\cdot \frac12\, dx_{t-1}
= \frac12.
\]
同理，
\[
p(x_t=4.5 \mid y_{1:t-1})
= \int_{4}^{4.5} 1\cdot \frac12\, dx_{t-1}
= \frac14.
\]
这说明连续情形下，积分并不是额外的神秘操作；它只是把“所有可能的旧位置”对当前点 \(x_t\) 的贡献连续地累加起来。收到观测后，再按
\[
p(x_t \mid y_{1:t})
\propto
p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1})
\]
把靠近观测的位置抬高、把远离观测的位置压低，这就是连续版的更新。

\subsection{预测步}

由附录~\hyperref[app:total-prob]{全概率公式}，
\[
p(x_t \mid y_{1:t-1})
= \int_{\mathcal X} p(x_t \mid x_{t-1}) p(x_{t-1} \mid y_{1:t-1}) \, dx_{t-1}.
\]
这一步把上一时刻的后验经由状态转移核推到当前，称为预测分布。

\subsection{更新步}

由附录~\hyperref[app:bayes-formula]{Bayes 公式}，
\[
p(x_t \mid y_{1:t})
= \frac{p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1})}{p(y_t \mid y_{1:t-1})}.
\]
分母只是归一化常数，因此常写成
\[
p(x_t \mid y_{1:t})
\propto p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1}).
\]

合起来，Bayes 滤波就是一条两步递推：
\begin{align*}
\text{预测：}\quad
p(x_t \mid y_{1:t-1})
&= \int_{\mathcal X} p(x_t \mid x_{t-1}) p(x_{t-1} \mid y_{1:t-1}) \, dx_{t-1}, \\
\text{更新：}\quad
p(x_t \mid y_{1:t})
&\propto p(y_t \mid x_t)\, p(x_t \mid y_{1:t-1}).
\end{align*}

难点不在公式，而在于这两个分布通常没有解析表达式。粒子滤波就是对这条递推的数值近似。

\section{用粒子近似分布}

如果你之前没系统学过 \(\pi_t^N\)、Dirac 质量、经验测度、先验/预测/后验分布这些术语，可以先跳到附录~\hyperref[app:notation]{术语与记号速查}；那一节专门解释这些词到底是什么意思，以及通常在哪些课程里第一次见到。

设一批粒子与权重为
\[
\{x_t^{(i)}, w_t^{(i)}\}_{i=1}^N,
\qquad
w_t^{(i)} \ge 0,\quad \sum_{i=1}^N w_t^{(i)} = 1.
\]
粒子滤波用经验测度
\[
\pi_t^N(dx)
= \sum_{i=1}^N w_t^{(i)} \delta_{x_t^{(i)}}(dx)
\]
近似目标后验 \(\pi_t(dx) = p(x_t \mid y_{1:t})\,dx\)。这里 \(\delta_{x_t^{(i)}}\) 是在粒子位置上的 Dirac 质量。若想先看两个直接可算的“近似后验”例子，可跳到附录~\hyperref[app:posterior-examples]{近似后验的两个朴素例子}。

于是对任意测试函数 \(\varphi\)，其后验期望可用加权和近似：
\[
\E[\varphi(x_t) \mid y_{1:t}]
= \int_{\mathcal X} \varphi(x)\,\pi_t(dx)
\approx \sum_{i=1}^N w_t^{(i)} \varphi(x_t^{(i)}).
\]

特别地，后验均值和二阶矩分别近似为
\[
\hat{x}_t \approx \sum_{i=1}^N w_t^{(i)} x_t^{(i)},
\qquad
\E[x_t x_t^\top \mid y_{1:t}] \approx \sum_{i=1}^N w_t^{(i)} x_t^{(i)} {x_t^{(i)}}^\top.
\]

\section{从重要性采样推到权重递推}

\subsection{静态重要性采样}

设目标密度为 \(\pi(x)\)，难以直接采样；提议分布为 \(q(x)\)，容易采样，且 \(q(x) > 0\) 在 \(\pi(x)\) 的支撑上成立。则
\[
\E_\pi[\varphi(x)]
= \int_{\mathcal X} \varphi(x)\pi(x)\,dx
= \int_{\mathcal X} \varphi(x)\frac{\pi(x)}{q(x)} q(x)\,dx
= \E_q[\varphi(x)\omega(x)],
\]
其中未归一化重要性权重定义为
\[
\omega(x) := \frac{\pi(x)}{q(x)}.
\]

若 \(x^{(i)} \sim q\)，则自归一化估计为
\[
\E_\pi[\varphi(x)]
\approx \sum_{i=1}^N \bar{w}^{(i)} \varphi(x^{(i)}),
\qquad
\bar{w}^{(i)} = \frac{\omega(x^{(i)})}{\sum_{j=1}^N \omega(x^{(j)})}.
\]

\subsection{序贯重要性采样}

在滤波问题中，目标分布随时间变化。设整条状态轨迹为 \(x_{0:t}\)。目标是后验
\[
\pi_t(x_{0:t}) := p(x_{0:t} \mid y_{1:t}),
\]
而提议分布取作
\[
q_t(x_{0:t} \mid y_{1:t})
= q_{t-1}(x_{0:t-1} \mid y_{1:t-1}) q_t(x_t \mid x_{0:t-1}, y_{1:t}).
\]
对应的未归一化权重为
\[
\omega_t(x_{0:t})
= \frac{\pi_t(x_{0:t})}{q_t(x_{0:t} \mid y_{1:t})}.
\]

利用
\[
\pi_t(x_{0:t})
\propto p(y_t \mid x_t) p(x_t \mid x_{t-1}) \pi_{t-1}(x_{0:t-1}),
\]
可得递推形式
\[
\omega_t^{(i)}
\propto \omega_{t-1}^{(i)}
\frac{p(y_t \mid x_t^{(i)}) p(x_t^{(i)} \mid x_{t-1}^{(i)})}
{q_t(x_t^{(i)} \mid x_{0:t-1}^{(i)}, y_{1:t})}.
\]
这是序贯重要性采样的核心公式。

\subsection{Bootstrap 粒子滤波}

若直接选提议分布
\[
q_t(x_t \mid x_{0:t-1}, y_{1:t}) = p(x_t \mid x_{t-1}),
\]
则上式中的状态转移项约掉，权重递推大幅简化为
\[
\omega_t^{(i)} \propto \omega_{t-1}^{(i)} p(y_t \mid x_t^{(i)}).
\]
这就是最经典的 Bootstrap particle filter。它的优点是实现简单；缺点是没有利用当前观测去设计更聪明的提议分布，故在观测很尖锐时容易权重退化。

\section{重采样：为什么必须做，以及怎么判断何时做}

\subsection{权重退化}

如果长时间只做重要性加权，不做重采样，通常会出现少数粒子拥有几乎全部权重，其余粒子权重接近零。此时虽名义上有 \(N\) 个粒子，实际有效样本远小于 \(N\)。

常用诊断量是有效样本数
\[
\ess
:= \frac{1}{\sum_{i=1}^N (w_t^{(i)})^2}.
\]
若所有权重都相等，则 \(\ess = N\)；若一个粒子独占全部权重，则 \(\ess = 1\)。

\subsection{重采样的数学作用}

重采样把带权粒子
\[
\{x_t^{(i)}, w_t^{(i)}\}_{i=1}^N
\]
转换为等权粒子
\[
\{\tilde{x}_t^{(i)}, 1/N\}_{i=1}^N
\]
并满足
\[
\E\!\left[\frac{1}{N}\sum_{i=1}^N \varphi(\tilde{x}_t^{(i)})
\Bigm| \{x_t^{(j)},w_t^{(j)}\}_{j=1}^N \right]
= \sum_{j=1}^N w_t^{(j)} \varphi(x_t^{(j)}).
\]
也就是说，重采样在条件期望意义下不改变经验测度，但会牺牲多样性并引入额外方差。

\subsection{常见选择}

最简单的是 multinomial resampling。它直观，但方差偏大。实践中常用 systematic 或 stratified resampling，以降低采样方差。

\section{完整算法}

Bootstrap 粒子滤波可写成下述步骤：

\begin{enumerate}
  \item 初始采样：\(x_0^{(i)} \sim p(x_0)\)，令 \(w_0^{(i)} = 1/N\)。
  \item 预测：对每个粒子采样
  \[
  x_t^{(i)} \sim p(x_t \mid x_{t-1}^{(i)}).
  \]
  \item 加权：计算未归一化权重
  \[
  \omega_t^{(i)} = w_{t-1}^{(i)} p(y_t \mid x_t^{(i)}),
  \]
  再归一化成 \(w_t^{(i)}\)。
  \item 若 \(\ess < N_{\mathrm{thres}}\)，则重采样并把权重重置为 \(1/N\)。
\end{enumerate}

\section{算例一：双峰观测下的权重更新}

本节故意选一个一维、离散而短小的例子，用来手算权重。

\subsection{模型设定}

设当前时刻的预测粒子位置为
\[
x_t^{(1)}=-3,\quad x_t^{(2)}=-1,\quad x_t^{(3)}=1,\quad x_t^{(4)}=3,
\]
预测后它们等权，即 \(w_{t|t-1}^{(i)} = 1/4\)。

观测模型取为
\[
y_t = x_t^2 + v_t,\qquad v_t \sim \Normal(0,1).
\]
现在观测到 \(y_t = 9\)。

\subsection{逐个计算似然}

由高斯似然，
\[
p(y_t=9 \mid x_t^{(i)})
\propto \exp\!\left(-\frac{(9-(x_t^{(i)})^2)^2}{2}\right).
\]
四个粒子的平方分别为 \(9,1,1,9\)，故未归一化权重与
\[
\exp(0),\ \exp(-32),\ \exp(-32),\ \exp(0)
\]
成正比。记 \(a=\exp(-32)\approx 1.27\times 10^{-14}\)，则归一化后
\[
w_t^{(1)} = \frac{1}{2+2a}\approx \frac{1}{2},
\qquad
w_t^{(4)} = \frac{1}{2+2a}\approx \frac{1}{2},
\]
\[
w_t^{(2)} = w_t^{(3)} = \frac{a}{2+2a}\approx 6.35\times 10^{-15}.
\]

\subsection{这组数字说明了什么}

更新后，后验几乎完全集中在 \(-3\) 与 \(3\) 两个粒子上。这个结果非常重要：粒子滤波没有把答案压成 \(0\)，而是保留了两个对称峰。若此时用单个高斯去拟合后验，均值会落在 \(0\) 附近，但 \(0\) 恰好是观测最不支持的位置之一。

\subsection{有效样本数}

此时
\[
\ess
= \frac{1}{2(1/2)^2 + 2(6.35\times 10^{-15})^2}
\approx 2.
\]
虽然共有 \(4\) 个粒子，但有效样本数约为 \(2\)。继续迭代后若退化加重，就应触发重采样。

\section{算例二：一维非线性运动的两步递推}

上一节只手算了一次更新；这一节写出一个完整的预测-更新-重采样回合。

\subsection{模型}

取状态模型
\[
x_t = \frac{1}{2}x_{t-1} + w_t,\qquad w_t \sim \Normal(0,1),
\]
观测模型
\[
y_t = x_t^2 + v_t,\qquad v_t \sim \Normal(0,1).
\]
假设上一时刻重采样后得到四个等权粒子
\[
x_{t-1}^{(1)}=-4,\quad x_{t-1}^{(2)}=-2,\quad x_{t-1}^{(3)}=2,\quad x_{t-1}^{(4)}=4.
\]

\subsection{预测}

为了算例简单，假设一次实际采样结果恰为
\[
x_t^{(1)}=-3,\quad x_t^{(2)}=-1,\quad x_t^{(3)}=1,\quad x_t^{(4)}=3.
\]
这组值与状态方程是相容的，因为对应噪声样本分别为 \(-1,0,0,1\)。

\subsection{更新}

若观测仍是 \(y_t=9\)，则权重就是上一节算出的结果，近似为
\[
\left(\frac{1}{2},\,0,\,0,\,\frac{1}{2}\right).
\]

\subsection{重采样}

若做 multinomial resampling，则新粒子会以概率 \(1/2\) 从 \(-3\) 和 \(3\) 中抽取。一次可能的重采样结果为
\[
\tilde{x}_t^{(1)}=-3,\quad
\tilde{x}_t^{(2)}=-3,\quad
\tilde{x}_t^{(3)}=3,\quad
\tilde{x}_t^{(4)}=3.
\]
这说明重采样虽把权重重新拉平，但也明显减少了粒子多样性。这正是后续很多改进方法想要处理的问题。

\section{实现时真正要盯的量}

\subsection{粒子数 \(N\)}

\(N\) 太小时，后验分布会被表示得过于粗糙；\(N\) 太大时，计算开销上升。没有万能公式，通常只能依据维度、观测尖锐程度和实时性要求去调。

\subsection{提议分布}

Bootstrap 方案最简单，但不是最优。若观测很强，应该尝试设计更靠近后验的提议分布，否则权重容易一轮就塌。

\subsection{重采样阈值}

常见做法是在 \(\ess < N/2\) 或 \(\ess < 0.3N\) 时重采样。阈值过高会导致频繁重采样、样本贫化；阈值过低则权重退化严重。

\section{如果只记住几句话}

\begin{enumerate}
  \item 粒子滤波是在近似整条 Bayes 滤波递推，而不是只在做“随机采样”。
  \item 它用经验测度去逼近后验，因此天然可以表示多峰和强非线性。
  \item 重要性采样给出了权重公式，重采样则是在控制权重退化。
  \item 它的根本代价是：表达能力来自大量样本，算力与退化问题永远绕不开。
\end{enumerate}

在这份基础笔记之后，粒子滤波还可以与最优输运或神经网络结合。但那是两条不同扩展线，应分别讨论，而不应混在一篇里。

\appendix

\section{术语与记号速查}\label{app:notation}

\subsection{这些东西通常在哪些课程里第一次见到}

如果按课程来源粗分，大致是这样：
\begin{enumerate}
  \item 概率论与数理统计：先验、后验、条件概率密度、Bayes 公式。
  \item 随机过程或状态估计：状态空间模型、预测分布、滤波递推。
  \item 测度论概率或更理论化的概率课：Dirac 质量、测度、经验测度这类写法。
  \item Monte Carlo / 统计计算：重要性采样、粒子系统、经验分布近似。
\end{enumerate}

所以如果你之前主要学的是“随机变量 + 密度函数 + 期望”那一套，而没正式学过测度论，那么 \(\pi_t^N(dx)\) 这种写法看着陌生是完全正常的。

\subsection{\(\pi_t\) 与 \(\pi_t^N\) 到底是什么}

这里的 \(\pi_t\) 只是“时刻 \(t\) 的目标后验分布”的另一种写法。连续情形下，它对应
\[
\pi_t(dx) = p(x_t \mid y_{1:t})\,dx.
\]

而 \(\pi_t^N\) 表示“用 \(N\) 个粒子构造出来的近似分布”：
\[
\pi_t^N(dx)
= \sum_{i=1}^N w_t^{(i)} \delta_{x_t^{(i)}}(dx).
\]

这里上标 \(N\) 不是幂次，而是在提醒你：这个对象依赖于粒子数 \(N\)。\(N\) 变大时，通常希望 \(\pi_t^N\) 越来越接近真正的后验 \(\pi_t\)。

\subsection{Dirac 质量是什么}

\(\delta_a\) 表示“把全部质量都压在点 \(a\) 上”的分布，也叫 Dirac 质量或点质量。最核心的特征是：对任意测试函数 \(\varphi\)，都有
\[
\int_{\mathcal X} \varphi(x)\,\delta_a(dx) = \varphi(a).
\]

如果你暂时不想碰测度论，可以把它粗略理解成：
\begin{quote}
\(\delta_a\) 就是在说“这个随机量不散开，它只取点 \(a\)”。
\end{quote}

所以
\[
\sum_{i=1}^N w_t^{(i)} \delta_{x_t^{(i)}}
\]
的意思就是：把权重 \(w_t^{(i)}\) 分配给点 \(x_t^{(i)}\)，从而得到一个“由很多带权点组成的分布”。

\subsection{经验测度是什么}

经验测度这个词听上去抽象，其实只是“把样本云写成分布对象”。

例如，若有三个等权样本
\[
2,\ 5,\ 9,
\]
那么对应的经验测度就是
\[
\frac13 \delta_2 + \frac13 \delta_5 + \frac13 \delta_9.
\]

它的意义是：以后你要算均值、方差或任意函数的期望时，不必每次都口头说“对三个样本取平均”，而可以统一写成“对经验测度积分”。比如
\[
\int_{\mathcal X} x\,
\left(
\frac13 \delta_2 + \frac13 \delta_5 + \frac13 \delta_9
\right)(dx)
= \frac{2+5+9}{3}.
\]

因此，粒子滤波里的经验测度不是新物理对象，只是把“粒子 + 权重”这堆东西打包成一个分布。

\subsection{先验、预测、后验分别是什么}

这三个概念彼此接近，但含义并不相同。

\begin{enumerate}
  \item 先验：在尚未利用当前观测之前，对状态所持有的分布性认识。
  \item 预测分布：把上一时刻后验通过状态转移推到当前时刻后得到的分布，即 \(p(x_t \mid y_{1:t-1})\)。
  \item 后验：融合了当前观测之后的分布，即 \(p(x_t \mid y_{1:t})\)。
\end{enumerate}

在滤波语境里，可以将三者的关系概括为：
\begin{quote}
先由上一时刻信息形成预测分布，再结合当前观测完成后验更新。
\end{quote}

\subsection{为什么正文里要用这些写法}

因为粒子滤波的本质不是只计算单个数值，而是在递推整条分布。只要关心的不仅是均值，而是完整的不确定性结构，那么 \(\pi_t\)、\(\pi_t^N\)、\(\delta_a\) 这一套写法会比单独书写密度函数更紧凑，也更适合同时处理离散与连续情形。

\subsection{近似后验的两个朴素例子}\label{app:posterior-examples}

\paragraph{例 1：离散状态时，近似后验就是带权计数}
设状态空间只有三个位置
\[
\mathcal X = \{A,B,C\}.
\]
假设真实后验为
\[
\pi_t(\{A\})=0.1,\qquad
\pi_t(\{B\})=0.3,\qquad
\pi_t(\{C\})=0.6.
\]

现在若粒子滤波给出 \(N=5\) 个等权粒子
\[
C,\ C,\ B,\ C,\ A,
\]
则经验测度就是
\[
\pi_t^5
= \frac15 \delta_A + \frac15 \delta_B + \frac35 \delta_C.
\]

这时它对三个状态给出的近似概率分别是
\[
\pi_t^5(\{A\})=\frac15,\qquad
\pi_t^5(\{B\})=\frac15,\qquad
\pi_t^5(\{C\})=\frac35.
\]

它与真实后验
\[
(0.1,\ 0.3,\ 0.6)
\]
并不完全相同，但已经抓住了最主要的结构：状态 \(C\) 概率最大，状态 \(A\) 最小。这里“近似后验”没有任何神秘之处，本质上就是“看有多少粒子落在各个状态上”。

\paragraph{例 2：连续状态时，近似后验就是带权点去逼近平滑分布}
现在设状态是连续位置，真实后验是一条平滑密度曲线，例如大致集中在 \(x=2\) 附近。粒子滤波给出三个带权粒子
\[
x_t^{(1)}=0,\qquad x_t^{(2)}=2,\qquad x_t^{(3)}=3,
\]
\[
w_t^{(1)}=0.2,\qquad w_t^{(2)}=0.5,\qquad w_t^{(3)}=0.3.
\]
那么近似后验写成
\[
\pi_t^3(dx)
= 0.2\,\delta_0(dx)+0.5\,\delta_2(dx)+0.3\,\delta_3(dx).
\]

这不表示真实后验真的只在 \(0,2,3\) 三个点取值，而是表示：
\begin{quote}
我们暂时只用这三个带权点来代表整条连续后验曲线。
\end{quote}

例如，它给出的后验均值近似为
\[
\int_{\mathcal X} x\,\pi_t^3(dx)
= 0.2\times 0 + 0.5\times 2 + 0.3\times 3
= 1.9.
\]

若要近似区间 \([1.5,3.5]\) 上的后验概率，则只需把落在区间内的粒子权重相加：
\[
\pi_t^3([1.5,3.5]) \approx 0.5+0.3=0.8.
\]

因此，连续情形下所谓“近似后验”，本质上就是：真实对象是一条连续密度曲线，而计算机里我们改用有限个带权点来替代它，并用这些权重去近似均值、区间概率和其他期望量。

\section{基础概率公式附录}

\subsection{全概率公式}\label{app:total-prob}

设 \(X\) 与 \(Y\) 具有联合密度 \(p(x,y)\)，其中 \(x \in \mathcal X\)。则边缘密度可由条件密度积分得到：
\[
p(y) = \int_{\mathcal X} p(y \mid x)\, p(x)\, dx.
\]

在条件化情形下，如果再给定一个额外信息集 \(\mathcal G\)，同样有
\[
p(y \mid \mathcal G)
= \int_{\mathcal X} p(y \mid x,\mathcal G)\, p(x \mid \mathcal G)\, dx.
\]

粒子滤波预测步正是在 \(\mathcal G = y_{1:t-1}\) 的条件下，对上式的直接应用。

\subsection{Bayes 公式}\label{app:bayes-formula}

在同样设定下，若 \(p(y) > 0\)，则后验密度满足
\[
p(x \mid y) = \frac{p(y \mid x)\, p(x)}{p(y)}.
\]
其中分母也可以借助全概率公式写成
\[
p(y) = \int_{\mathcal X} p(y \mid x)\, p(x)\, dx.
\]

若给定额外信息集 \(\mathcal G\)，则条件版 Bayes 公式为
\[
p(x \mid y,\mathcal G)
= \frac{p(y \mid x,\mathcal G)\, p(x \mid \mathcal G)}
{p(y \mid \mathcal G)}.
\]

粒子滤波更新步对应的是 \(\mathcal G = y_{1:t-1}\) 的特殊情形。
