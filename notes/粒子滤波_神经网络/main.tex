\section{写在前面：这一篇默认你已经知道什么}

本笔记默认你已经知道基础粒子滤波的三件事：第一，后验由粒子与权重近似；第二，权重来自重要性采样；第三，重采样是为了解决退化。这里不再重写这些基础，而只讨论神经网络如何嵌入粒子滤波。

本文只谈粒子滤波与神经网络的结合，不讨论最优输运，也不讨论三者同时混合。

\section{问题从哪里冒出来}

经典粒子滤波的理论框架很清楚，但在真实任务里经常遇到三类困难：

\begin{enumerate}
  \item 状态转移模型 \(p(x_t \mid x_{t-1})\) 写得不够准。
  \item 提议分布 \(q(x_t \mid x_{0:t-1}, y_{1:t})\) 选得太差，导致权重快速退化。
  \item 原始观测过于高维，例如图像、波形或点云，直接写观测似然 \(p(y_t \mid x_t)\) 很难。
\end{enumerate}

神经网络并不是来替代 Bayes 递推，而是来替代其中最难手工建模的一部分。

\section{统一视角：网络究竟插在哪个位置}

粒子滤波的核心递推是
\[
\omega_t^{(i)}
\propto \omega_{t-1}^{(i)}
\frac{p(y_t \mid x_t^{(i)}) p(x_t^{(i)} \mid x_{t-1}^{(i)})}
{q(x_t^{(i)} \mid x_{0:t-1}^{(i)}, y_{1:t})}.
\]
因此网络自然有三种插入点：

\begin{enumerate}
  \item 用网络参数化状态转移模型 \(p_\theta(x_t \mid x_{t-1},u_t)\)。
  \item 用网络参数化提议分布 \(q_\phi(x_t \mid x_{t-1}, y_t)\)。
  \item 用网络把原始观测 \(o_t\) 编码成低维特征 \(z_t=f_\psi(o_t)\)，再定义 \(p(z_t \mid x_t)\)。
\end{enumerate}

其中第一类是在学动力学，第二类是在学如何更聪明地采样，第三类是在学观测表征。

\section{第一类结合：用网络学动力学残差}

\subsection{基本形式}

设你已有一个粗糙物理模型
\[
x_t = f_{\mathrm{phys}}(x_{t-1},u_t) + w_t.
\]
若其系统性偏差明显，可以令网络学习残差项 \(r_\theta\)，写成
\[
x_t = f_{\mathrm{phys}}(x_{t-1},u_t) + r_\theta(x_{t-1},u_t) + w_t.
\]
于是转移密度写为
\[
p_\theta(x_t \mid x_{t-1},u_t)
= \Normal\!\Bigl(f_{\mathrm{phys}}(x_{t-1},u_t)+r_\theta(x_{t-1},u_t),\,Q\Bigr).
\]

\subsection{为什么这有意义}

这样做保留了物理先验的骨架，只把难写准的偏差交给网络。与纯黑盒模型相比，它更容易训练，也更容易解释。

\subsection{训练方式}

若离线数据里有状态对 \((x_{t-1},x_t)\)，可直接最小化负对数似然
\[
\mathcal{L}(\theta)
= \sum_t \frac{1}{2}
\Bigl(x_t - f_{\mathrm{phys}}(x_{t-1},u_t)-r_\theta(x_{t-1},u_t)\Bigr)^\top
Q^{-1}
\Bigl(x_t - f_{\mathrm{phys}}(x_{t-1},u_t)-r_\theta(x_{t-1},u_t)\Bigr)
+ \mathrm{const}.
\]
若 \(Q=\sigma^2 I\)，这退化为加权平方误差。

\section{第二类结合：用网络学提议分布}

\subsection{为什么提议分布关键}

基础粒子滤波常用 Bootstrap 提议
\[
q(x_t \mid x_{t-1}, y_t)=p(x_t \mid x_{t-1}),
\]
它完全忽略当前观测 \(y_t\)。如果观测很尖锐，采出的粒子大多会落在后验低概率区，于是权重退化严重。

\subsection{网络参数化的提议}

一种更聪明的做法是直接令
\[
q_\phi(x_t \mid x_{t-1}, y_t)
= \Normal\!\bigl(\mu_\phi(x_{t-1}, y_t),\, \Sigma_\phi(x_{t-1}, y_t)\bigr),
\]
其中 \(\mu_\phi,\Sigma_\phi\) 由网络输出。此时粒子采样变为
\[
x_t^{(i)} \sim q_\phi(\cdot \mid x_{t-1}^{(i)}, y_t).
\]
对应权重递推为
\[
\omega_t^{(i)}
\propto \omega_{t-1}^{(i)}
\frac{p(y_t \mid x_t^{(i)}) p_\theta(x_t^{(i)} \mid x_{t-1}^{(i)})}
{q_\phi(x_t^{(i)} \mid x_{t-1}^{(i)}, y_t)}.
\]

\subsection{一个关键解释}

网络提议并不是把 Bayes 公式改掉，而是在改变“你从哪里采样”。只要权重按上式校正，理论上目标后验仍然不变。网络的价值，是让更多粒子落在真正重要的区域，从而提高样本效率。

\section{第三类结合：用网络学观测特征}

\subsection{原始观测太复杂时怎么办}

设传感器给出的不是简单标量 \(y_t\)，而是高维原始观测 \(o_t\)，例如图像。直接写 \(p(o_t \mid x_t)\) 往往不现实。

一种常见做法是先通过编码器 \(f_\psi\) 得到低维特征
\[
z_t = f_\psi(o_t),
\]
再用较简单的似然模型
\[
p(z_t \mid x_t) = \Normal(h(x_t), R).
\]
于是权重更新变成
\[
\omega_t^{(i)} \propto \omega_{t-1}^{(i)} p(z_t \mid x_t^{(i)}).
\]

\subsection{它的实质}

这等于把“复杂感知问题”与“状态估计问题”拆开处理。网络先把图像变成适合滤波的表征，粒子滤波再负责不确定性传播与多峰后验表示。

\section{一个统一的小车例子}

考虑一维小车位置 \(x_t\) 与控制输入 \(u_t\)。粗糙物理模型写成
\[
x_t = x_{t-1} + u_t + w_t,
\qquad
w_t \sim \Normal(0,1).
\]
但在湿滑路面上，车辆会系统性少走一点，真实模型更接近
\[
x_t = x_{t-1} + u_t - 0.4u_t + w_t.
\]
如果物理模型没有这项阻滞偏差，粒子会整体偏右。

\subsection{数值设定}

设 \(u_t=2\)，上一时刻有三个等权粒子
\[
x_{t-1}^{(1)}=4,\quad x_{t-1}^{(2)}=5,\quad x_{t-1}^{(3)}=6.
\]
现有观测来自摄像头编码器，输出一个近似位置特征 \(z_t=6.2\)，且
\[
p(z_t \mid x_t)=\Normal(x_t,\,0.25).
\]

\section{算例一：学习动力学残差前后有什么差别}

\subsection{不用网络残差}

若直接用粗糙模型 \(x_t=x_{t-1}+2+w_t\)，忽略噪声均值，只看预测中心，则三个预测中心为
\[
6,\ 7,\ 8.
\]
对观测 \(z_t=6.2\) 的似然与
\[
\exp\!\left(-\frac{(6.2-6)^2}{2\times 0.25}\right),\ 
\exp\!\left(-\frac{(6.2-7)^2}{2\times 0.25}\right),\ 
\exp\!\left(-\frac{(6.2-8)^2}{2\times 0.25}\right)
\]
成正比，即
\[
\exp(-0.08),\ \exp(-1.28),\ \exp(-6.48).
\]
约为
\[
0.923,\ 0.278,\ 0.0015.
\]
归一化后权重约为
\[
0.768,\ 0.231,\ 0.001.
\]

\subsection{加入网络学习的阻滞残差}

设网络已学到残差 \(r_\theta(x_{t-1},u_t)\approx -0.8\)，则预测中心改为
\[
5.2,\ 6.2,\ 7.2.
\]
此时似然与
\[
\exp(-2),\ \exp(0),\ \exp(-2)
\]
成正比，约为
\[
0.135,\ 1,\ 0.135.
\]
归一化后权重约为
\[
0.107,\ 0.787,\ 0.107.
\]

\subsection{解释}

没有网络残差时，粒子整体偏右，只有最左边粒子勉强贴近观测；加入残差后，中间粒子恰好与观测对齐，后验结构更合理。这说明网络不是在替代滤波，而是在修正错误的动力学先验。

\section{算例二：学习提议分布如何减少退化}

\subsection{Bootstrap 提议}

仍用上一节设定。若基础提议只根据动力学采样，可能产生三个新粒子
\[
6.8,\ 7.5,\ 8.1.
\]
对 \(z_t=6.2\) 的似然将急剧衰减，因此大部分权重集中到 \(6.8\) 那个粒子上，\(\ess\) 很小。

\subsection{网络提议}

若网络输出
\[
q_\phi(x_t \mid x_{t-1}, z_t) = \Normal(6.2,\,0.25),
\]
则采样更可能落在 \(6\) 到 \(6.5\) 附近。例如一次采样得到
\[
6.0,\ 6.2,\ 6.4.
\]
它们对观测的似然都不低，归一化后的权重会更加均匀。即便还需用
\[
\omega_t^{(i)}
\propto \omega_{t-1}^{(i)}
\frac{p(z_t \mid x_t^{(i)}) p_\theta(x_t^{(i)} \mid x_{t-1}^{(i)})}
{q_\phi(x_t^{(i)} \mid x_{t-1}^{(i)}, z_t)}
\]
做严格校正，退化程度通常仍显著减轻。

\section{训练与实现时的注意点}

\subsection{别把网络输出当真理}

网络转移模型、网络提议和网络观测编码都只是模型的一部分。只要它们与真实分布有偏差，粒子滤波就必须继续用权重校正和重采样来维持后验一致性。

\subsection{训练目标要和最终用途对齐}

学动力学残差时，可用一步预测误差或负对数似然。学提议分布时，更合理的目标往往不是简单回归，而是让提议分布更贴近真实后验，从而减小权重方差。学观测编码时，则要确保编码保留与状态估计有关的信息。

\subsection{网络会引入额外不稳定性}

如果训练分布与部署分布相差太大，网络学到的模型很容易失效。此时粒子滤波虽然还能工作，但权重退化可能比纯物理模型更糟。

\section{如果只记住几句话}

\begin{enumerate}
  \item 网络最常见的三种插入点是：动力学、提议分布、观测特征。
  \item 它提升的是模型能力或采样效率，而不是取消 Bayes 校正。
  \item 学动力学残差适合“物理骨架基本对，但细节有系统偏差”的情形。
  \item 学提议分布适合“观测很强，Bootstrap 提议太浪费粒子”的情形。
  \item 学观测特征适合“观测原始维度太高，似然难手写”的情形。
\end{enumerate}
